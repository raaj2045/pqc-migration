# Contributing

This is a research artifact accompanying the paper *"Framework for
Migrating Legacy Blockchain Accounts to Post-Quantum Systems"*. It is
**not** an actively-maintained software product.

The repository is published so that the paper's claims are
reproducible and the engineering choices behind ML-DSA-44 in Cosmos
SDK can be inspected end-to-end. We accept issues and pull requests
in the spirit of academic record-keeping but cannot promise turnaround
times.

## Issues

Bug reports against the paper artefacts are welcome — open an issue
on GitHub. Useful issues include: a reproduction step that doesn't
work on the documented prerequisites, an inconsistency between the
paper text and the code, or a measurement that doesn't reproduce on a
reference platform.

Out of scope: feature requests, refactors, broader Cosmos SDK
support questions (those belong with [upstream
cosmos-sdk](https://github.com/cosmos/cosmos-sdk)), and questions
about real-world deployment (this is a research prototype — see
[`SECURITY.md`](SECURITY.md)).

## Pull requests

Small fixes (typos, broken paths, dependency bumps that keep CI
green) are welcome. Larger changes should reference an open issue
first so the change can be evaluated against the published paper.

## Contact

For paper-related correspondence, contact the corresponding author
listed in [`CITATION.cff`](CITATION.cff). For confidential
vulnerability reports, see [`SECURITY.md`](SECURITY.md).
