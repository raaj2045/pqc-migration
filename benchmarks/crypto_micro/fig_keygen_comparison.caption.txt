Fig. 1: Key generation latency for secp256k1 (ECDSA) versus ML-DSA-65 (FIPS 204), bar chart with logarithmic ordinate.
Median of 10 Go testing.B runs per key type, each with testing.B's own iteration count, on an AMD Ryzen 5 7600X with 6 logical CPUs under Go 1.26.5; ML-DSA-65 is measured through the Cosmos SDK v0.55 key type the chain uses, which re-parses the packed key on every call.
ML-DSA-65 key generation costs 69.8 microseconds versus 0.10 microseconds for secp256k1, a 677x slowdown; key generation happens once per account, so it does not bear on transaction throughput.
