Fig. 11: Commit success rate (committed transactions divided by submitted transactions, expressed as a percentage) as a function of submitted load for secp256k1 versus ML-DSA-44, three subplots one per validator-set size N in {4, 7, 16}, with a light gray reference line at the 90-percent strict-criteria threshold.
Single 300-second run per (N, target rate, scheme) cell on AMD Ryzen 5 7600X under Go 1.23.5, four to sixteen Cosmos SDK validators in Docker containers each capped at one CPU.
ML-DSA-44 first falls below 90 percent commit success at target rate 50 for N=16 while secp256k1 still passes the threshold there; for both schemes the curve plummets between target rates 100 and 200 as the per-sender mempool admission window saturates and the antehandler begins rejecting future-sequence transactions.
